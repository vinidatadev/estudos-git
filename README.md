# Estudos Git - Análise de Vendas

## 📋 Descrição

Projeto de estudo focado em práticas de Git/GitHub e análise de dados com Python. Este repositório demonstra um workflow completo de desenvolvimento, desde a criação de branches até o merge na branch principal.

## 🎯 Objetivos

- Implementar workflow Git profissional
- Desenvolver análise de dados de vendas
- Praticar documentação de código
- Aplicar Conventional Commits

## 📁 Estrutura do Projeto

```
estudos-git/
├── src/
│   └── analise_vendas.py
├── data/
│   └── vendas_sample.csv
├── docs/
├── .gitignore
├── README.md
└── requirements.txt
```

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/vinidatadev/estudos-git.git
cd estudos-git
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Execute a análise:
```bash
python src/analise_vendas.py
```

## 📊 Funcionalidades

- Análise estatística de dados de vendas
- Visualização de tendências
- Relatórios automatizados

## 🛠️ Tecnologias Utilizadas

- Python 3.8+
- Pandas
- Matplotlib
- Seaborn
